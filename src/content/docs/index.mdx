## Choose the right surface

Use the browser tools at [tamperbox.dev](https://tamperbox.dev) when you want a visual workflow or local processing; each documented tool's method, finding reference and repair guide are under [Tool pages](/tools/). Use the API when an application needs a single documented operation. Use the MCP server when an agent needs to discover schemas and compose calls.

<div class="tb-callout"><strong>Data boundary:</strong> browser-local tools keep supported inputs on the device. Server checks and MCP API calls send their operation inputs to the configured Tamperbox API.</div>

## What this site covers

- Setup for the public MCP server and local stdio package
- Code-mode discovery and execution patterns
- Operation families and input shapes
- Limits, evidence boundaries, security, and privacy
- Contribution paths for the public documentation repository

The [Tamperbox MCP repository](https://github.com/oceanrescue/tamperbox-mcp) remains the source of truth for package behavior, versioned schemas, tests, and deployment records. This site turns those contracts into task-focused guidance.
